# SeeScout 3.3 – Light Edition

SeeScout ist eine weltweit nutzbare Angel-PWA mit heller, freundlicher Oberfläche.

## Enthalten
- Weltweite Orts-/Gewässersuche und OpenStreetMap-Karte
- Wetterdaten von Open-Meteo am ausgewählten Kartenpunkt
- Wissenschaftliche Fisch-Beobachtungsdaten über GBIF (keine Fanggarantie)
- Allgemeiner Köderberater für Egli, Hecht, Zander, Forelle und Karpfen
- Digitaler Köderkoffer, lokales Fangtagebuch und Ausflugs-Stoppliste
- Beste-Angelzeit-Hinweise und Community-Demo
- PWA-Grundgerüst für Installation auf iPad

## Ehrliche Datenhinweise
Diese Version enthält **keine echte Fang-Hotspot-Heatmap**, keine verifizierte Tiefen-/Bodenkarte und keine geprüften Uferzugangs- oder Angelrechtsdaten. Diese Bereiche erklären die Datenlage, statt erfundene Werte anzuzeigen. GBIF enthält wissenschaftliche Beobachtungen, nicht aktuelle Fangmeldungen. Die Ködertipps sind allgemeine Richtwerte.

## Veröffentlichung
Alle Dateien aus dem ZIP in das Stammverzeichnis (Root) deines GitHub-Repositories laden. Nicht die ZIP-Datei selbst als einzelne Datei hochladen. Bestehende Dateien ersetzen und neue Dateien hinzufügen. Danach GitHub Pages auf `main` und `/ (root)` belassen und auf den grünen Actions-Lauf warten.

## Externe Dienste
- OpenStreetMap für Kartenkacheln
- Open-Meteo für Wetter und Ortsuche
- GBIF für wissenschaftliche Beobachtungsdaten

Diese Funktionen benötigen Internet. Bitte beachte die Nutzungsbedingungen der Dienste.

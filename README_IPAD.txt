SEESCOUT 3.3 AUF DEM IPAD

1. ZIP-Datei in der App "Dateien" antippen, damit iPadOS sie entpackt.
2. Den entpackten Ordner öffnen.
3. Die einzelnen Dateien in das Stammverzeichnis deines GitHub-Repositories hochladen. Nicht nur die ZIP-Datei hochladen.
4. Vorhandene Dateien mit gleichem Namen ersetzen. Neue Dateien wie smart_fishing.js (falls vorhanden) hinzufügen.
5. In GitHub Pages prüfen: Branch main, Ordner /(root).
6. Warten, bis der Pages-Workflow erfolgreich abgeschlossen ist.
7. Webseite in Safari öffnen. Falls noch die alte Version erscheint, einmal vollständig neu laden oder ?v=33 an die Webadresse hängen.

WICHTIG:
Falls du bereits eigene Supabase-Werte in config.js eingetragen hast, sichere diese Datei zuerst. Die mitgelieferte config.js enthält leere Platzhalter. Trage deine eigenen Werte danach wieder ein.
Richte Online-Konten am besten mit einer erwachsenen Vertrauensperson ein.
